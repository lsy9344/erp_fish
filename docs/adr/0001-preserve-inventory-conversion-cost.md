# 냉동 전환은 별도 재고 이동으로 기록한다

생물 재고의 일부를 냉동 품목으로 옮길 때 판매나 손실로 기록하지 않고, 전환 기록과 선입선출 배분을 별도로 보존한다. 원천 재고는 오래된 lot부터 줄이고 같은 수량과 원가를 냉동 lot으로 1:1 이동해 재고 수량·원가·매출원가가 이후 저장과 이월에서도 바뀌지 않게 한다.

대상 품목은 사용자가 고르지 않는다. 생물 품목명 앞에 `활냉)`을 붙이고 같은 규격의 냉동 품목을 자동 생성하거나 재사용한다. 전환 배분에는 원래 생물 lot의 입고일을 보존하되, 냉동 lot의 입고일은 냉동 전환이 일어난 장부의 영업일로 표시해 날짜별 단가와 판매가를 따로 관리한다.
